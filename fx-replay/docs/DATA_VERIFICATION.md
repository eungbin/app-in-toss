### 1-3. "공공누리"와의 관계
ECOS 약관·지침에는 공공누리 유형 표기가 없다. 실질 조건은 **BOK 작성 통계 = 공공누리 1유형과 동등(출처표시만)**, **타 기관 작성 통계 = 비상업 한정(공공누리 2유형과 동등)**. 즉 "ECOS는 1유형"이라는 단일 판단은 틀리고, **통계표 단위로 작성기관(`ORG_NAME`)을 보고 판단**해야 한다.

### 1-4. API 운영 정보
- 호출 형식: `https://ecos.bok.or.kr/api/StatisticSearch/{KEY}/json/kr/{시작건}/{끝건}/{통계표코드}/{주기}/{시작일}/{종료일}/{항목코드}` (실제 호출로 확인)
- `sample` 키: 1회 10건까지 조회 가능(개발·검증용). 실제 수집에는 인증키 필요(무료, 이메일 가입).
- 일일 호출 한도: 공개 문서에서 직접 확인 못함(2차 자료는 1~2만 건/일). 우리 용도(1회성 수집 후 정적 번들)에서는 무의미.
- 2026-09-08 18:30~22:30 시스템 작업 순단 예정(공지).

### 5-1. 시·고·저·종이 어긋나는 행이 있다

ECOS는 시가·고가·저가·종가를 **각각 별도의 통계 항목**으로 발행하고, 종가는 **15:30 기준**이다. 그래서 드물게 종가가 그날의 고가·저가 범위를 벗어난다.

| 시계열 | 어긋난 행 | 비율 | 최대 오차 | 발생 연도 |
|---|---|---|---|---|
| usdkrw | 4 / 8,777 | 0.05% | 15.10원 | 2001, 2002, 2009, 2017 |
| cnykrw | 14 / 2,645 | 0.53% | 9.00원 | 2015~2021 |

예) 2001-05-24 시 1,279 / 고 1,283.5 / 저 1,277 / **종 1,285** — 종가가 고가보다 높다.

**대응**: 이용지침의 "임의로 변경하거나 왜곡하지 않아야 한다" 조항을 지키기 위해 **번들 데이터는 ECOS가 발행한 값 그대로 둔다.** 대신 화면에 그릴 때만 네 값을 모두 포함하도록 보정한다.

- `src/engine/normalize.ts`의 `candleHigh` = `max(h, o, c)`, `candleLow` = `min(l, o, c)`
- 차트·기간 최고/최저·공유 카드·자동 해설이 모두 이 값을 쓴다
- 검증 테스트는 (a) 원자료의 어긋난 비율이 1% 미만인지, (b) 보정을 거치면 캔들 기하가 항상 유효한지를 각각 확인한다

이 처리는 원자료를 바꾸지 않으므로 출처 표시 의무와 충돌하지 않는다.

| 분기(Q) | 126 |
| **일(D)** | **7** |
| 반기(S)·반월(SM) | 2 |
| 주기 없음(분류 노드) | 226 |

**일별보다 짧은 주기는 없다.** 한국은행은 경제통계 제공기관이지 시세 벤더가 아니라 일중 데이터를 다루지 않는다. 분봉·시간봉은 ECOS로 불가능하다.

외부 소스도 막혀 있다. 인베스팅닷컴·트레이딩뷰 등은 분봉 차트를 제공하지만 약관이 상업적 이용과 재배포를 명시적으로 금지한다. 원화는 자유화된 통화가 아니라 무료 FX 틱 데이터(Dukascopy 등)에도 원/달러 커버가 거의 없다.

**반대 방향(주봉·월봉)은 가능하다.** 일봉을 기간 단위로 묶는 표준 리샘플링이므로 원자료를 바꾸지 않는다. `src/engine/resample.ts`에서 런타임에 집계하며, 번들에는 일봉만 담는다.


### 5-3. 월봉 지원 후 원자재·해외지수 재검토 (2026-09-07)

주봉·월봉을 구현하면서 "월별만 있는 자산도 이제 되는 것 아닌가"를 다시 확인했다. **주기 장벽은 사라졌지만 나머지 둘이 남는다.**

#### 원자재 (902Y003, IMF 작성) — 여전히 불가

1. **라이선스**: ECOS 지침상 타 기관 작성이라 IMF 승인 필요. ECOS를 우회해 IMF에서 직접 받는 길도 막혀 있다. IMF 약관은 자료를 "개인적·비상업적 용도로만" 허용하고 **재판매·재배포·2차적저작물 작성 권리를 주지 않는다.** 상업적 재이용은 copyright@imf.org 허가 사항이다.
2. **OHLC 없음**: 월 단위 단일 값이다. 실측 확인 — 2008-01 금 889.6 달러/트로이온스, WTI 92.98 달러/배럴. 한 달에 값 하나뿐이라 캔들을 그릴 수 없고 선 그래프만 가능하다.

두 번째가 특히 중요하다. 우리 환율 월봉은 **일봉을 집계해 만들기 때문에 진짜 OHLC가 나온다.** 그 달의 변동 폭이 봉 하나에 담긴다. 원자재 월봉에는 그 정보가 아예 없어서, 같은 "월봉"이라도 정보량이 다르다.

#### 해외 주가지수 (902Y002, OECD 작성) — 라이선스는 열려 있으나 권하지 않음

OECD 기본 라이선스는 **CC BY 4.0**으로, 출처 표시만으로 상업 이용을 포함한 자유 이용이 가능하다(IMF와 정반대). 미국 1957년, 일본 1959년부터 월별 데이터가 있다.

다만 (a) 역시 월 단일 값이라 OHLC가 없고 (b) **"주가지수"라 금융상품 조항에서 환율보다 가깝다.** KOSPI를 미룬 이유가 라이선스만은 아니었다는 점을 기억할 것. 도입하려면 사전 상담에서 별도로 확인하는 편이 안전하다.

#### 현재 판단

| 자산 | 주기 | 라이선스 | OHLC | 결론 |
|---|---|---|---|---|
| 원자재 (IMF) | 월 ✓ | ✗ 승인 필요 | ✗ | 승인 전 불가 |
| 해외지수 (OECD) | 월 ✓ | ✓ CC BY 4.0 | ✗ | 가능하나 심사 리스크 |
| KOSPI·KOSDAQ (KRX) | 일 ✓ | ✗ 승인 필요 | 부분 | 승인 대기 |
| **환율 (한국은행)** | 일 ✓ | ✓ 출처표시 | ✓ | 사용 중 |

원자재를 도입하려면 **copyright@imf.org 상업 이용 문의**가 유일한 경로다. KRX 문의(051-662-2000)와 병행할 수 있다. 승인이 나면 엔진 변경 없이 데이터만 추가하면 되지만, OHLC가 없는 자산은 차트 모드를 선(line)으로 하나 더 만들어야 한다.
