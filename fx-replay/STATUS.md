루트에서 `npm run status` 로 본다. 이 파일에는 **파일에서 읽어낼 수 없는 것만** 적는다 —
콘솔 등록·심사·정산처럼 앱인토스 쪽에만 있는 사실이다.

## 심사 반려 (2026-09-08) — 고쳐서 승인받았다

**받은 사유 원문**

> 기타 1. 출시할 미니앱 번들에는 테스트용 광고 그룹 ID를 넣을 수 없어요.
> 실제 발급받은 광고 그룹 ID만 사용해주세요.

**원인.** `@ait/kit` 이 테스트 광고 그룹 ID를 모듈 최상위 상수(`TEST_AD_GROUPS`)로 갖고 있었다.
최상위 참조라 트리셰이킹이 되지 않아 **출시 번들에 문자열이 남았다.** 런타임에는 `configureAds()` 로
실 ID 를 덮어쓰지만 **심사는 런타임 동작이 아니라 번들 문자열을 본다.**

세션의 판단 착오도 원인이다. 반려 전에 번들을 열어 `ait-ad-test-*` 를 보았고, 런타임에 쓰이지 않는
죽은 문자열이라 무해하다고 넘겼다.

**대응**
- kit 에서 `TEST_AD_GROUPS` 를 제거. 기본값을 빈 문자열로 두고 `hasGroup()` 가드로 ID 가 비면 광고를 붙이지 않는다
- 테스트 ID 는 앱 `.env` 로만 들어간다
- `scripts/check-bundle.ts` — **빌드 산출물을 직접 스캔한다.** 설정 검사(`check-prod-config.ts`)로는 못 잡는다
- 확인: 출시 번들에 테스트 ID 0건, 실 ID 2건
- 루트 [PLAYBOOK](../docs/PLAYBOOK.md) 6장에 한 줄로 남겼다
