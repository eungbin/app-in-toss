## 1. 화면 구조 (읽어낸 것)

단일 진입, **홈 한 화면 + 시트 3종**. 자체 헤더 없음(토스 네비 바 사용).

```
홈 (월 단위)
├─ 월 네비  ‹ 2026년 9월 ›   [⚙ 설정]
├─ 카드: 이번 달 예상 실수령액  ─ 세전 급여 / 주휴수당 / 예상 공제
├─ 카드: 급여 계산  (n시간 · n일)
│    근무 급여 / 주휴수당 n회 / 세전 급여 / 소득세·지방소득세 / 4대보험 근로자 부담분 / 예상 실수령액
├─ 카드: 근무 달력  [기록 추가]  — 오늘 강조, 날짜 탭 → 기록 시트
├─ 카드: 근무 기록  n건 — 빈 상태 "아직 기록이 없어요"
└─ 하단 고정 버튼  [+ 근무 기록하기]

시트: 근무 기록      (닫기 / 제목 / 폼 / 계산 미리보기 / 저장)
시트: 설정           (근무지 목록·추가 / 내 데이터: CSV 내보내기 / 계산 기준)
시트: 근무지 등록   (2-5 — 스크롤 3장)
```

## 2. 화면별 내용

### 2-1. 홈 (legacy-06, legacy-05)
- 월 네비 `‹ 2026년 9월 ›`, 오른쪽 톱니(설정).
- **보라색 카드** "이번 달 예상 실수령액 **0원**", 하단 3열: 세전 급여 0원 / 주휴수당 0원 / 예상 공제 -0원.
- **급여 계산 카드**, 우측 상단 `0시간 · 0일`:
  - 근무 급여 0원
  - 주휴수당 `0회` +0원
  - **세전 급여** 0원
  - 소득세·지방소득세 -0원
  - 4대보험 근로자 부담분 -0원
  - **예상 실수령액** 0원 (강조 박스)
- **근무 달력 카드**, 우측 `기록 추가` 링크. 일요일 빨강, 오늘(9일) 보라 원. 날짜를 누르면 기록 시트.
- **근무 기록 카드** `0건`. 빈 상태: "아직 기록이 없어요 / 달력에서 날짜를 누르거나 아래 버튼으로 추가해 보세요."
- 하단 고정 `+ 근무 기록하기`.

### 2-2. 근무 기록 시트 (legacy-03, legacy-02)
| 필드 | 형태 | 기본값·비고 |
|---|---|---|
| 근무지 | 셀렉트 | 등록된 근무지 중 선택 |
| 날짜 | 날짜 피커 | `2026. 09. 01.` |
| 출근 / 퇴근 | 시간 피커 2열 | `오전 9:00` / `오후 6:00` |
| 휴게시간 | 숫자 + 단위 `분` | 60 |
| 추가수당 | 숫자 + 단위 `원` | 0 |
| 휴일 근무 | 체크박스 카드 | 부제 "5인 이상 설정에서 휴일 가산 참고액을 계산해요." |
| 메모 `선택` | 텍스트 | placeholder "예: 마감 근무" |

계산 미리보기(연보라 박스): 실근무 **8시간** / 기본급 **82,560원** / **예상 급여 82,560원**.
각주: "야간은 22:00~06:00 기준이며 휴게시간은 야간 구간에서 먼저 차감해 보수적으로 계산해요."
버튼: `근무 기록 저장`.

### 2-3. 설정 시트 (legacy-04)
- **근무지** 섹션, 우측 `추가`. 항목: `● 테스트` / `일반 근로소득 · 시급 10,320원 · 매월 10일` → 상세(›).
  - 근무지에 **소득 유형·시급·급여일**이 있다. 사업장 규모(5인)도 여기 있을 것(기록 시트 각주로 추정).
- **내 데이터**: `CSV로 기록 내보내기 ›`
  - 각주: "근무지와 근무 기록은 외부 서버로 전송하지 않고 이 기기에만 저장해요. 앱 데이터가 삭제될 수 있으니 필요한 기록은 주기적으로 내보내 주세요."
- **계산 기준** 박스: "2026년 최저임금, 근로기준법의 주휴·가산 기준, 국세청 간이세액표, 2026년 사회보험료율을 참고해요. 계산값은 급여 확인을 위한 예상액이며 법적 증빙은 아니에요."

### 2-4. 토스 공통 메뉴 (legacy-01)
`···` 를 누르면 나오는 플랫폼 시트(앱 정보 보기·이용 후기·고객센터·홈 화면에 추가·공유하기·설정). 앱 코드가 아니다. 참고만.

### 2-6. 기록이 있는 홈 (legacy-07, legacy-08)
- 달력: 기록 있는 날에 **근무지 색 점 + 금액 축약 `83천`** (82,560 → 천 단위 반올림).
- 근무 기록 목록 항목: `● 9월 9일 (수)` / 부제 `테스트 · 09:00–18:00 · 8시간` / 우측 `82,560원`. 최신순.
- 실수령 카드: **137,470원**, 세전 급여 165,120원 / 주휴수당 0원 / 예상 공제 -27,650원.
- 급여 계산 `16시간 · 2일`: 근무 급여 165,120 / 주휴수당 `0회` +0 / 세전 급여 165,120 / 소득세·지방소득세 -0 / 4대보험 근로자 부담분 -27,650 / 예상 실수령액 137,470.
- 9/8(화)·9/9(수) 16시간이면 주 15시간을 넘는데 주휴 0회다. 주휴 자동 계산이 꺼져 있었거나, **주가 끝나기 전엔 개근을 판정하지 않는** 규칙일 수 있다. 새 판 스펙에서 정한다(주가 끝난 뒤 확정, 진행 중인 주는 "예정" 표시가 자연스럽다).

## 3. 골든 값 (화면에서 확인)

| 케이스 | 입력 | 화면 값 | 검산 |
|---|---|---|---|
| 평일 1일 | 09:00~18:00, 휴게 60분, 시급 10,320 | 실근무 8시간, 기본급 82,560원 | 8 × 10,320 = 82,560 ✓ |
| 2일 합계 | 위 × 2 | 16시간 · 2일, 근무 급여 165,120원 | ✓ |
| 소득세 | 세전 165,120, 가족 1 | 0원 | 간이세액표 106만 원 미만 → 0 ✓ |
| 4대보험 | 세전 165,120, 3종 전부 켬 | **-27,650원** | 아래 |

### 3-1. 구판 4대보험 27,650원의 내역 (역산)
net-pay 엔진(`computeNet`, 2026-09-09 기준)으로 같은 입력을 돌리면 **32,355원**이다. 차이의 원인을 역산했다.

| 항목 | 구판(역산) | net-pay 엔진 | 차이 원인 |
|---|---|---|---|
| 국민연금 | 19,470 | 19,475 | 둘 다 하한 410,000 × 4.75%. 구판은 **10원 절사**, net-pay 는 원 단위 |
| 건강보험 | 5,930 | 10,080 | 구판은 165,120 × 3.595% 그대로. net-pay 는 **월 보험료 하한(총액 20,160 → 근로자 10,080)** 적용 |
| 장기요양 | 770 | 1,320 | 구판은 절사한 건보료 5,930 × 13.14% 를 다시 10원 절사 |
| 고용보험 | 1,480 | 1,480 | 동일 |
| 합계 | **27,650** ✓ | 32,355 | |

**결정(스펙에 반영)**: 새 판은 **net-pay 엔진을 그대로 쓴다.** 그 값은 이미 원문 대조 골든 테스트를 통과했고, 건강보험 하한은 고시에 있는 규칙이다. 구판 화면 값은 "구조를 확인하는 근거" 로만 쓰고 공제 골든 값으로 삼지 않는다. 다만 월 60시간 미만 근로자는 직장가입 대상이 아니므로 4대보험 토글이 꺼진 상태가 알바의 기본값일 수 있다 — 기본값은 PRD 에서 정한다.

- 시간 → 급여 구간(가산·주휴)은 구판 화면에 케이스가 없다. FACT_CHECK 에서 근로기준법 원문 산술로 만든다.
- 구판 규칙: 휴게시간을 **야간 구간에서 먼저 차감**(보수적). 새 판도 유지한다 — 사용자에게 유리하지 않은 쪽으로 계산하는 것이 "예상액" 앱의 안전한 기본값이다.

## 4. 못 본 것과 처리 방침

| 항목 | 상태 | 처리 |
|---|---|---|
| CSV 내보내기 동작 | 사용자 확인: **실제 CSV 파일로 내보내진다** | SDK 3.x 에서 같은 경로가 되는지 착수 시 조사(공유 시트 vs 저장). Q1 은 (a) 로 기운다 |
| 야간·휴일 가산 표시 | 미촬영 | 새 판 스펙에서 정한다. 기록 시트 미리보기에 `기본급 / 연장 / 야간 / 휴일 / 추가수당` 행을 조건부로 보여 주는 안 |
| 주휴수당 n회 표시 | 0회 상태만 | 스펙에서 "주 단위 확정" 규칙과 함께 정한다 |

## 5. 새 판에 그대로 가져갈 것 / 바꿀 것 (제안)

- **그대로**: 홈 첫 카드 = 이번 달 예상 실수령액(부제와 일치). 급여 계산 카드 6행. 기록 시트 필드 7개. 근무지 폼 구조(시급·규모·급여일·소득 유형·주휴 토글·공제 옵션·보험 3토글·색상). 달력 점+금액 축약. 계산 기준·기기 저장 각주(심사 방어 문구로 이미 좋다).
- **바꿀 것**: 공제 계산은 net-pay 엔진(3-1). 광고 위치(배너는 스크롤 마지막, 리워드 게이트 자리). 세이프에어리어·백스택은 `@ait/kit`. 하단 고정 버튼과 배너 충돌은 시안에서 푼다. 근무지 폼이 길다 — 세금·4대보험 섹션은 "일반 근로" 일 때만 펼친다.
