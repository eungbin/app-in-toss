# net-pay — 세후로 말해줘

받고 싶은 **세후 월급으로 필요한 연봉을 역산**하는 앱인토스 미니앱. 정방향 계산(연봉 → 실수령), 퇴직금, 연차수당도 함께 제공한다.

- 기획·설계: [PRD](docs/PRD.md) → [기능 명세](docs/FUNCTIONAL_SPEC.md) → [화면 흐름](docs/SCREEN_FLOW.md)
- 공용 패키지: [`@ait/kit`](../packages/ait-kit) — [설계](../docs/SHARED_PACKAGE.md)

## 시작하기

```bash
# 의존성은 모노레포 루트에서 설치한다
(cd .. && npm install)
npm run data:dev   # 개발용 합성 간이세액표 생성 (실제 표 없이 앱 실행)
npm run dev        # http://localhost:5174
```

## 실제 간이세액표 넣기

개발용 합성 표는 구조만 같고 값이 다르다. `check:data`가 프로덕션 빌드를 차단하므로 출시 전에 실제 표로 바꿔야 한다.

1. 홈택스 > 세금신고 > 원천세 신고 > **근로소득 간이세액표**에서 조견표(엑셀)를 받는다.
2. 엑셀을 CSV로 저장해 `data-src/tax-table/<시행일>.csv`로 둔다. 열 순서는 `이상, 미만, 1명 … 11명`.
3. 표 앞의 **비고**에서 자녀 차감액과 1,000만 원 초과 산식을 읽어 `data-src/tax-table/<시행일>.meta.json`에 적는다.
4. `npm run data:build` → `npm run check:data`

## 스크립트

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 (5174) |
| `npm run check` | 타입체크 + 문구 린트 + 테스트 |
| `npm run data:dev` | 개발용 합성 세액표 생성 |
| `npm run data:build` | 실제 세액표 CSV → 번들 JSON |
| `npm run check:data` | 합성 데이터·미확인 요율·산식 미확정 차단 |
| `npm run build` | check + check:data + vite build + ait build |

## 알아 둘 것

- **정방향은 단조 증가가 아니다.** 세액표 계단과 국민연금 절사 때문에 연봉이 오를 때 실수령이 잠깐 내려가는 지점이 있다(최대 월 2,417원). 역산은 이를 전제로 격자 탐색 + 선형 보정을 쓴다. 기능 명세 3-4절.
- **저소득 구간에는 계단이 있다.** 과세 소득이 생기는 순간 보험료 하한이 걸려 실수령이 한 번 떨어진다. 제도상 동작이며 테스트로 고정돼 있다.
- 모든 계산은 기기 안에서 끝난다. 서버가 없고 입력값을 어디로도 보내지 않는다.
