# net-pay — 세후로 말해줘

받고 싶은 **세후 월급으로 필요한 연봉을 역산**하는 앱인토스 미니앱. 정방향 계산(연봉 → 실수령), 상여 분리, 퇴직금·퇴직소득세, 연차수당도 함께 제공한다.

- 기획·설계: [PRD](docs/PRD.md) → [기능 명세](docs/FUNCTIONAL_SPEC.md) → [화면 흐름](docs/SCREEN_FLOW.md)
- 계산 검증: [FACT_CHECK.md](docs/FACT_CHECK.md) — 골든 케이스 37건(홈택스·고용노동부·노동OK 계산기 대조 포함)과 남은 확인 항목
- 공용 패키지: [`@ait/kit`](../packages/ait-kit) — [설계](../docs/SHARED_PACKAGE.md)

## 시작하기

```bash
# 의존성은 모노레포 루트에서 설치한다
(cd .. && npm install)
npm run data:build # 원본 HWPX → 번들 JSON (원본은 data-src/tax-table/ 에 들어 있다)
npm run dev        # http://localhost:5174
```

## 간이세액표 원본

원본은 소득세법 시행령 별표2다. 표·비고·초과 산식을 전부 원본에서 읽으므로 사람이 숫자를 옮겨 적는 단계가 없다.

```bash
npm run data:fetch   # 국가법령정보센터에서 현행 별표2 평문 받기 → data-src/tax-table/<시행일>.txt
npm run data:build   # 파싱·검증 → src/data/tax-tables.json
```

| 출처 | 형식 | 파서 | 비고 |
|---|---|---|---|
| 국가법령정보센터 소득세법 시행령 별표2 | 평문 텍스트 | `scripts/law-byl.ts` | **1순위.** 현행 시행판이 항상 있다. 법령 본문은 저작권 보호 대상이 아니다(저작권법 제7조 제1호) |
| 공공데이터포털 국세청_근로소득 간이세액표 | HWPX | `scripts/hwpx.ts` + `scripts/zip.ts` | 개정 반영이 늦다(2026-09-07 기준 2024-02-29 판). 과거 시행판 보관용 |

번들에는 `2024-02-29`와 `2026-03-01` 두 시행판이 들어 있다. 시간축이 연도별로 해당 시행판을 골라 쓴다.

새 개정판이 나오면 `npm run data:fetch`가 개정일을 읽어 파일을 만든다. 시행일이 개정일과 다르므로
`scripts/fetch-tax-table.ts`의 `EFFECTIVE_FROM`에 매핑을 한 줄 추가해야 한다(모르면 스크립트가 알려주고 멈춘다).

## 알아 둘 것

- **정방향은 단조 증가가 아니다.** 가장 큰 계단은 과세 월급이 표 상한(1,000만 원)을 넘는 지점이다. 별표2가 상한 기준 세액에 25,000원을 더하기 때문에 연봉 122,400,012원에서 실수령이 **월 27,499원** 떨어진다. 역산은 연봉 120만 원 격자(이 위에서는 단조)로 탐색한 뒤 칸 안을 훑고, 화면에 내보내는 만 원 단위 연봉에서도 목표가 지켜지는지 따로 확인한다. 기능 명세 3-4절.
- **저소득 구간에는 계단이 있다.** 과세 소득이 생기는 순간 보험료 하한이 걸려 실수령이 한 번 떨어진다. 제도상 동작이며 테스트로 고정돼 있다.
- 모든 계산은 기기 안에서 끝난다. 서버가 없고 입력값을 어디로도 보내지 않는다.
