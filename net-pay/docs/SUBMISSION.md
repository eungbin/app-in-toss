## 1. 콘솔 등록 입력값

그대로 복사해 넣을 수 있게 정리했다.

### 1-1. 기본 정보

| 필드 | 값 | 비고 |
|---|---|---|
| 앱 유형 | **비게임** | |
| 카테고리 | **유틸리티** | 재테크·금융을 피한다. 금융 조항 렌즈로 검토될 여지를 줄이기 위함(PRD 2-1 A2) |
| 앱 이름(국문) | **세후로 말해줘** | |
| 앱 이름(영문) | **NetPay** | 15자 이내 명사형 ✓ (6자) |
| 부제 | **받고 싶은 세후 월급으로 연봉 역산** | |
| 고객문의 이메일 | `.env` 의 `VITE_SUPPORT_EMAIL` 과 **같은 값**을 넣는다 | 빌드 가드가 비어 있으면 막는다 |
| 앱 로고 | 600×600 PNG, 정사각형, 둥근 모서리 없음 | `assets/logo-600.png` (**초안**, `npx tsx scripts/gen-logo.ts` 로 재생성) |
| 스크린샷 | 세로 636×1048 PNG | 아래 1-3 구성안대로 촬영 |

### 1-2. 상세 설명 (콘솔 "상세 설명" 필드)

콘솔 가이드가 요구하는 **"서비스 접속 → 행동 → 결과"** 흐름으로 작성했다.

> 국세청이 공개한 근로소득 간이세액표와 4대 사회보험 요율로 월급 실수령액을 계산하는 도구입니다.
>
> 앱에 들어오면 "세후로 월 얼마를 받고 싶은지" 묻는 입력창이 나옵니다. 금액을 넣으면 그만큼 받기 위해 필요한 연봉이 바로 계산되고, 국민연금·건강보험·장기요양·고용보험·소득세·지방소득세가 항목별로 얼마씩 빠지는지 함께 보여 줍니다. 반대로 연봉을 넣어 월 실수령액을 확인할 수도 있습니다.
>
> 같은 연봉이 몇 년 전이었다면 실수령이 얼마였는지 연도별로 비교해 볼 수 있고, 결과를 카드 한 장으로 만들어 저장하거나 공유할 수 있습니다. 퇴직금과 미사용 연차수당 계산기도 함께 들어 있습니다.
>
> 모든 결과는 공개된 세액표와 공단 요율에 따른 참고용 계산이며, 화면마다 적용 기준일과 함께 표시됩니다. 금융 상품을 소개하거나 연결하지 않고, 연봉을 얼마로 하라거나 이직을 권하는 안내도 하지 않습니다. 입력한 금액은 서버로 전송되지 않고 기기 안에서만 계산됩니다. 사용자 간 경쟁, 현금성 보상, 확률형 요소가 없습니다.

### 1-3. 스크린샷 구성안 (5장)

| 순서 | 화면 | 담을 것 |
|---|---|---|
| 1 | 홈 (역산) | "세후로 월 300만 원 받고 싶어요" 입력과 "연봉 약 4,035만 원이 필요해요" 결과. **차별점이 첫 장에 보여야 한다** |
| 2 | 공제 상세 | 항목별 월·연간 표와 기준일·면책 문구 |
| 3 | 시간축 | 연도별 막대 차트와 요율 표 |
| 4 | 협상 카드 | 4:5 카드 미리보기 |
| 5 | 퇴직금 또는 연차수당 | 산식 펼친 상태 |

**주의**
- 개발용 배너("개발용 합성 세액표입니다")가 보이면 안 된다. 실데이터 상태에서 촬영한다(현재 실데이터).
- 기준 문구가 `간이세액표 2026-03-01 시행`으로 나오는지 확인한다.

## 2. 채널톡 사전 상담 메시지

계산기라 fx-replay보다 위험이 낮지만, 세액을 다루므로 카테고리와 자문 해당 여부는 미리 확인하는 편이 낫다.

> 안녕하세요. 비게임 미니앱 출시를 준비 중이며, 카테고리와 심사 기준을 미리 확인받고 싶어 문의드립니다.
>
> **서비스 개요**
> 국세청이 공개한 근로소득 간이세액표(소득세법 시행령 별표2)와 4대 사회보험 요율로 월급 실수령액을 계산하는 도구입니다. 특징은 방향입니다. 기존 계산기가 "연봉 → 실수령"만 계산하는 것과 달리, 이 앱은 **"받고 싶은 세후 월급 → 필요한 연봉"을 역으로 계산하는 것이 첫 화면**입니다. 퇴직금·연차수당 계산기도 함께 제공합니다.
>
> **등록 예정 카테고리**: 유틸리티 (비게임)
>
> **심사 기준을 고려해 다음과 같이 설계했습니다**
> 1. **금융 상품을 다루지 않습니다.** 대출·적금·보험·카드·증권 어떤 상품도 노출·추천·연결하지 않습니다. 이 연봉이면 대출 한도가 얼마인지 같은 파생 기능도 넣지 않았습니다.
> 2. **세무 자문이 아닙니다.** 모든 결과에 "간이세액표·공단 요율 기준 참고용 계산입니다. 실제 공제액은 회사·개인 상황에 따라 다를 수 있어요", "연말정산 결과는 반영되지 않습니다", 적용 기준일을 함께 표시합니다. 연봉을 얼마로 하라거나 이직을 권하는 표현은 빌드 단계에서 자동으로 차단하고 있습니다.
> 3. **개인정보를 수집하지 않습니다.** 서버가 없습니다. 입력한 금액은 기기 안에서만 계산되고 어디로도 전송되지 않습니다. 저장은 사용자가 명시적으로 누른 경우에만 하고 전체 삭제 기능을 제공합니다.
> 4. **경쟁·보상 요소가 없습니다.** 순위, 현금성 보상, 확률형 요소가 없습니다.
>
> **데이터 출처**
> - 근로소득 간이세액표: 국가법령정보센터 소득세법 시행령 별표2 (2026-03-01 시행판), 공공데이터포털 국세청 파일(이용허락범위 제한 없음)
> - 4대보험 요율·상하한: 보건복지부고시(월별 건강보험료액의 상한과 하한, 국민연금 기준소득월액 하한액과 상한액), 고용노동부 고시
> - 데이터는 앱 번들에 정적으로 포함되며 런타임에 외부 서버를 호출하지 않습니다.
> - 앱 내 결과 화면과 설정 > 데이터 출처 화면에 출처와 확인일을 표기했고, "국세청·공단이 제공·인증한 서비스가 아닙니다"를 함께 넣었습니다.
>
> **수익화 항목**
> - 인앱 광고만 사용합니다. 보상형(광고를 보면 당일 자정까지 시간축 비교·저장 계산 비교·저장 20개가 열립니다), 배너(홈·상세·저장 목록 하단).
> - 핵심 기능인 역산·정방향 계산과 공제 상세, 퇴직금, 연차수당은 광고 없이 무제한 무료입니다.
> - 인앱 결제와 자체 현금성 보상은 없습니다.
>
> **여쭙고 싶은 것**
> 1. 위 설계로 **유틸리티** 카테고리 등록이 적절한지, 혹은 다른 카테고리를 권하시는지
> 2. 공개된 세액표로 세액을 계산해 보여 주는 것이 세무·금융 자문 관련 조항에 해당하는지
> 3. 광고 보상으로 "당일 자정까지 일부 기능 열기"를 주는 구조가 보상 정책에 맞는지
> 4. 매년 세액표·요율이 개정되면 데이터만 교체해 업데이트하게 되는데, 그때마다 심사가 필요한지
>
> 필요하시면 화면 흐름이나 문구 목록을 추가로 보내드리겠습니다. 감사합니다.

### 3-3. 남은 작업

**의존 순서가 있다.**

1. **정산 준비** — 사업자 정보·정산 정보 등록은 **완료**(2026-09-07). 사업자가 하나라 두 앱에 모두 적용된다.
   남은 것은 **팝빌 가입과 인증서 등록**이다. 광고 그룹 생성과는 독립적이라 병행할 수 있다.
   절차와 매월 승인 기한은 [docs/SETTLEMENT.md](../../docs/SETTLEMENT.md) 참고 —
   **역발행 미승인이 2회 이상이면 미니앱 운영이 중단될 수 있다.**
2. **광고 그룹 생성** — 콘솔 광고 그룹 관리에서 **앱마다 2개**(리워드·배너)를 만든다. 검토는 없고 생성 즉시 상세 화면에 광고 그룹 ID가 나온다. 단 구글 등록까지 최대 2시간이 걸려 그전에는 광고가 안 붙을 수 있다.

   | 광고 유형 | 그룹 이름(안) | 보상 이름 | 수량 |
   |---|---|---|---|
   | 리워드 | `netpay-rewarded-gate` | 오늘 하루 열기 | 1 |
   | 배너 | `netpay-banner-bottom` | — | — |

   미디에이션(광고 네트워크)은 앱 정보의 카테고리에 맞춰 자동 설정된다. 발급된 ID를 `.env` 의
   `VITE_AD_REWARDED_ID`·`VITE_AD_BANNER_ID` 에 넣는다.
3. **고객문의 이메일 확정** → `.env` 의 `VITE_SUPPORT_EMAIL` 과 콘솔 등록값을 같게 맞춘다.
4. **로고 확정** — 현재는 원화 기호 초안이다. 그대로 갈지 결정한다.
5. **스크린샷 5장 촬영** (1-3 구성안).
6. **QR 테스트** — `npm run build` 로 테스트 광고 ID 상태의 번들을 만들어 실기기 확인(3-2).
7. **출시 빌드** — `npm run build:release`. 실 광고 ID가 없으면 막힌다.
8. **심사 제출** — 영업일 3일, 카테고리에 따라 7일 이상.

**검증에 남은 것** (출시를 막지는 않는다)
- 4대보험 각 보험료의 절사 단위 — 공단 계산기로 대조. 영향 월 40원 이내. [FACT_CHECK 3-2](FACT_CHECK.md)
- 2021~2022년 국민연금 기준소득월액 상·하한, 고용보험 요율 변경 시점, 과거 건강보험 보수월액 상·하한 — 시간축에만 쓰이고 화면에 각주가 붙는다. [FACT_CHECK 3-3](FACT_CHECK.md)
- ~~퇴직금 대조~~ → **완료** (2026-09-07). 고용노동부 계산기와 2건 대조, 평균임금 내림 버그 수정. [FACT_CHECK H](FACT_CHECK.md)
