## 1. 검증 방법

기대값을 구현 코드로 만들면 자기 자신을 검증하는 셈이 된다. 그래서 두 경로만 쓴다.

1. **세액**: 원문 텍스트에서 구간 경계(`이상 미만`)로 직접 정규식을 걸어 11개 값을 읽는다.
   `scripts/hwpx.ts`의 순차 파싱과 다른 경로이므로 파서 버그와 독립적이다. 행이 한 번만 잡히는지도 단정한다.
2. **보험료**: 고시 숫자(요율·상하한)를 테스트 안에 리터럴 산술로 다시 적어 대조한다.

실수령 통합 케이스(21·22번)는 위 두 재료만으로 기대값을 조립한 뒤 `computeNet` 결과와 맞춘다.

## 3. 자동 검증이 안 되는 항목

아래는 사람이 한 번 확인해야 한다. 국세청·공단 계산기는 모두 자바스크립트 앱이라 서버에서 값을 받아올 수 없다(2026-09-07 확인: 홈택스·손택스·국가법령정보센터·4대사회보험 정보연계센터 모두 페이지 껍데기만 응답).

### 3-1. 2026-03-01 시행판 세액표 — **출시 블로커**

공공데이터포털은 2024-02-29 시행판까지만 올려 두었다. 2026-03-01 시행판은 자녀 차감액이
**20,830 / 45,830 / 2명 초과 1명당 33,330원**으로 바뀌었고, 2026년 국민연금 요율 인상(9.0 → 9.5%)이
연금보험료공제에 반영되므로 본문 세액도 달라질 가능성이 있다.

받는 곳: 홈택스 > 세금신고 > 원천세 신고 > 근로소득 간이세액표 (조견표)
넣는 곳: `data-src/tax-table/2026-03-01.hwpx` → `npm run data:build`
그때까지 `npm run check:data`가 프로덕션 빌드를 막는다.

### 3-3. 과거 연도 요율

`src/data/rates.json`의 `needsVerification`에 남아 있는 항목이다. 시간축 화면이 이 값을 쓰고,
미확인 행이 있으면 화면에 "일부 연도의 요율은 원문 대조를 마치지 않았어요"가 붙는다.

| 항목 | 미확인 연도 | 확인처 |
|---|---|---|
| 국민연금 기준소득월액 상·하한 | 2021 · 2022 | 보건복지부 「국민연금 기준소득월액 하한액과 상한액」 고시 연도별 개정 이력 |
| 고용보험 근로자 요율 변경 시점 | 2021 ~ 2022-06 (0.8%) | 고용노동부 고시 |
| 건강보험 보수월액보험료 상·하한 | 2021 ~ 2025 | 보건복지부 「월별 건강보험료액의 상한과 하한에 관한 고시」 연도별 |
| 건강보험 하한 20,160원의 성격 | 2026 | 총액인지 본인 부담인지 (구현은 총액으로 전제) |

2023-07-01 행의 상·하한(37만 ~ 590만)은 2024년 조정 안내가 "590만 → 617만, 37만 → 39만"이라고
밝혀 역으로 확인됐다. 2024·2025·2026 행은 원문에서 직접 확인했다.
