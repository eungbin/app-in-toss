# net-pay 상태

파생할 수 있는 것(광고 ID 단계, deploy 스크립트, 가드, 마지막 커밋)은 여기 적지 않는다.
루트에서 `npm run status` 로 본다. 이 파일에는 **파일에서 읽어낼 수 없는 것만** 적는다 —
콘솔 등록·심사·정산처럼 앱인토스 쪽에만 있는 사실이다.

- **단계**: QR 테스트 준비 — 콘솔 앱 등록 대기
- 갱신: 2026-09-08

## 콘솔

| 항목 | 상태 |
|---|---|
| 앱 등록 | **미완료** — 1차 기본 정보부터 (카테고리가 있어야 광고 그룹 미디에이션이 붙는다) |
| 카테고리 | 생활 > 편의 > 도구 |
| 광고 그룹 | **완료** (2026-09-08) 리워드·배너 2개. 실 ID는 `.env` 주석에만 |
| 검색 키워드 | 10개 확정 — [docs/SUBMISSION.md](docs/SUBMISSION.md) 1-4. 콘솔 등록은 미완료 |
| 상세 설명 500자 | **475자** (2026-09-08 확인). 첫 판 513자에서 줄였다 |
| 스크린샷 | 미촬영. 실기기에 띄워야 찍을 수 있다 |
| 번들 업로드 | **없음** — `.ait` 는 로컬에만 있다 |
| QR 테스트 | 미실시 |
| 심사 제출 | 미제출 |

## 정산 (사업자 공통 — 세 앱이 같이 쓴다)

사업자 정보·정산 정보 등록 완료(2026-09-07). 팝빌 일반회원 가입, 우리은행 전자세금용
공동인증서 등록 완료(2026-09-08). 절차와 매월 승인 기한은 [../docs/SETTLEMENT.md](../docs/SETTLEMENT.md).

## 다음 한 걸음

콘솔 앱 등록 + 1차 기본 정보 → `npm run deploy` → QR 테스트 + 스크린샷 → 2차 스크린샷 등록
→ `npm run deploy:release` → 그 번들로 테스트 1회 → 심사 요청.
자세한 순서와 의존 관계는 [docs/SUBMISSION.md](docs/SUBMISSION.md) 3-3.
