# 정산 절차 (사업자 공통)

| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.1 (2026-09-07) |
| 적용 범위 | **사업자 하나로 모든 미니앱에 공통.** 앱마다 다시 하지 않는다 |
| 근거 | 앱인토스 개발자센터 [정산 가이드](https://developers-apps-in-toss.toss.im/guide/settlement), [인앱 광고 가이드](https://developers-apps-in-toss.toss.im/guide/monetization/in-app-ad) (2026-09-07 확인) |
| 현재 상태 | 사업자 정보·정산 정보 등록 완료. **팝빌 가입과 인증서 등록이 남았다** |

---

## 1. 전체 순서

```
사업자 정보 등록 ─▶ 정산 정보 등록·검토 요청 (영업일 2~3일)
                          │
                          ├─▶ 광고 그룹 생성 (검토 없음, 즉시 ID 발급)
                          │      └─ 구글 등록까지 최대 2시간
                          │
                          └─▶ 팝빌 가입 + 인증서 등록  ← 지금 여기
                                 └─ 매월 역발행 세금계산서 승인 (수익이 생긴 다음 달부터)
```

광고 그룹 생성과 팝빌 준비는 **서로 독립적**이다. 광고를 먼저 붙여도 되고, 팝빌은 첫 수익이
생기기 전까지 끝내면 된다. 다만 첫 승인 요청 메일이 오기 전에 준비돼 있어야 안전하다.

---

## 2. 팝빌과 인증서가 왜 필요한가

광고 수익은 토스가 사업자에게 지급하는 대가다. **일반과세자**는 그 대가에 대해 토스에
세금계산서를 발행해야 한다. 앱인토스는 이걸 **역발행 방식으로만** 받는다.

| 방식 | 누가 작성하나 | 앱인토스 지원 |
|---|---|---|
| 정발행 | 공급자(나)가 직접 발행 | **지원 안 함.** "정발행으로 처리된 건은 광고수익 지급 대상에서 제외됩니다" |
| 역발행 | 공급받는 자(토스)가 작성해 보내고, 내가 **승인(전자서명)** | 이 방식만 |

가이드 원문: "세금계산서는 역발행 승인 방식으로만 처리되며, 원활한 처리를 위해
팝빌 가입 및 공인인증서 등록이 필요합니다."

- **팝빌**(popbill.com)은 전자세금계산서 플랫폼이다. 토스가 이 플랫폼으로 역발행하므로
  같은 곳에서 승인해야 한다.
- **인증서**는 세금계산서 발행이 전자서명을 요구하기 때문에 필요하다. 승인 버튼을 누를 때 서명한다.

> **간이과세자라면 이 절차가 전부 불필요하다.** "세금계산서 발행 없이 광고수익에 대한 정산금이 지급됩니다."
> 그러나 소프트웨어 개발·공급업(주업종 722000)은 **간이과세 배제 업종**이라 일반과세자다. 피할 수 없다.

## 3. 인증서 — 종류를 잘못 고르면 비싸다

여기서 가장 많이 막힌다. 쓸 수 있는 인증서가 정해져 있고, **가격이 25배 차이 난다.**

| 인증서 | 발급처 | 연 비용 | 용도 |
|---|---|---|---|
| **전자세금계산서용** ← 팝빌 권장, 우리 선택 | **은행** | 대체로 **4,400원** | 세금계산서 업무만 |
| 전자거래 범용 | 금융결제원·한국전자인증·코스콤·한국정보인증·한국무역정보통신 | 약 110,000원 | 조달청 입찰·인터넷뱅킹·전자민원까지 전부 |
| 팝빌 표준 공동인증서 | 팝빌인증센터 (cert.popbill.com) | 4만 원대 | 팝빌용 |

**쓸 수 없는 것**: 인터넷뱅킹 등 **금융거래용** 인증서, 타기관 발급 특수목적용 인증서.

### 헷갈리는 지점

"은행 인증서는 안 된다"가 아니다. 정확히는 이렇다.

- **안 되는 것** — 은행에서 발급한 **인터넷뱅킹·금융거래용** 인증서 (이미 갖고 있는 그것)
- **되는 것** — 은행에서 발급하는 **전자세금계산서용** 인증서 (따로 신청하는 다른 상품)

같은 은행에서 받지만 용도가 다른 별개 인증서다. 인터넷뱅킹 로그인 → 인증센터에
"전자세금용 공동인증서" 발급 메뉴가 따로 있다.

- 이미 **범용 인증서를 갖고 있으면 추가 발급이 필요 없다.** 그대로 팝빌에 등록한다.
- 팝빌이 주는 테스트용 인증서는 **테스트 환경 전용**이라 실제 발행에 쓸 수 없다.

### 3-1. 발급과 등록은 다른 곳에서 한다 — 여기서 헷갈린다

**팝빌의 "인증서 관리"는 발급처가 아니라 등록하는 곳이다.** 그래서 그 화면에는
4,400원짜리가 보이지 않는다. 팝빌은 자기 상품(팝빌 표준 공동인증서, 4만 원대)만 판다.

```
1) 은행에서 발급  ← 팝빌 아님
   주거래 은행 기업·개인사업자 인터넷뱅킹 → 인증센터
   → "전자세금용 공동인증서" 발급 신청 → 4,400원 결제 → 인증서 저장

2) 팝빌에 등록
   팝빌 로그인 → 전자세금계산서 → 관리 → 인증서 관리 → 인증서 등록
   → 1)에서 받은 인증서 선택
```

**인증서 발급 은행과 정산 계좌 은행은 같을 필요가 없다.** 인증서는 사업자등록번호에 묶이므로
어디서 받아도 팝빌에 등록된다. 정산 계좌가 카카오뱅크여도 인증서는 다른 곳에서 받으면 된다.

은행 쪽 확인 사항
- 개인 뱅킹이 아니라 **기업(개인사업자) 인터넷뱅킹**에서 발급한다. 미가입이면 그것부터 해야 한다.
- 메뉴 이름이 은행마다 다르다("전자세금용", "전자세금계산서용", "세금계산서용").
  인터넷뱅킹용·범용과 구분해서 고른다.
- 가격도 은행마다 다를 수 있다. 4,400원이 표준가로 알려져 있으나 확인한다.

### 3-2. 카카오뱅크 사업자 인증서 — 무료지만 팝빌 호환은 미확인

카카오뱅크가 2024년부터 **사업자 인증서를 무료로** 발급한다(기존 범용은 연 5~11만 원).
100% 비대면, 유효기간 1년, 만기 30일 전 앱에서 갱신. **단독 개인사업자만** 되고
법인·공동대표는 불가하다.

**그런데 카카오뱅크는 이것을 "민간 인증서"로 표기하고, 명시된 사용처가
국세청 홈택스·조달청 나라장터뿐이다("사용처는 순차 확대 예정").**
팝빌이 받는 것은 3장의 **공동인증서** 세 종류이고 카카오뱅크 인증서는 그 목록에 없다.
→ **팝빌에서 안 될 가능성이 높다.**

홈택스에서 세금계산서를 발행할 수 있다는 것과, 팝빌에서 토스의 역발행을 승인하는 것은 다른 일이다.

**권장 순서**
1. 발급이 무료·비대면이므로 **팝빌 고객센터에 등록 가능 여부를 먼저 문의**한다. 되면 0원으로 끝난다.
2. 안 되면 아래 중 하나
   | 방법 | 비용 | 조건 |
   |---|---|---|
   | 다른 시중은행 전자세금용 | 4,400원 선 | 그 은행 기업 인터넷뱅킹 필요 |
   | 공동인증기관 직접 발급 (한국정보인증 등) | 4,400원 선 | 은행 계좌 없이도 가능. 사업자명으로 발급된다 |
   | 팝빌 표준 공동인증서 | 4만 원대 | 확실하지만 비싸다. 매년 갱신 |

## 4. 해야 할 일

- [ ] **팝빌 가입** — [popbill.com](https://www.popbill.com) 에서 사업자등록번호로 가입.
      업태·종목 입력란은 **사업자등록증에 인쇄된 문구를 그대로** 옮긴다. 세금계산서에 그대로 찍힌다.

      | 항목 | 값 |
      |---|---|
      | 업태 | 정보통신업 |
      | 종목 | 응용 소프트웨어 개발 및 공급업 |
      | 업종코드 | 722000 (구 표준산업분류 58222). 게임 소프트웨어 개발은 제외되는 코드다 |

      위 업태·종목은 업종코드 722000의 표준 분류다. 등록증 표기가 다르면 **등록증을 따른다**.
- [ ] **인증서 발급** — 주거래 은행 인터넷뱅킹 → 인증센터 → **전자세금용 공동인증서**(연 4,400원 선).
      범용 인증서를 이미 갖고 있으면 이 단계를 건너뛴다
- [ ] **인증서 등록** — 팝빌 로그인 → 전자세금계산서 → 관리 → 인증서 관리 → 인증서 등록
- [ ] **포인트 잔액 확인** — 5장 참고. 역발행 기본 과금이 **공급자(우리) 부담**이라 잔액이 0이면 승인이 막힌다
- [ ] 콘솔에 첨부된 「[토스] 팝빌 역발행 세금계산서 안내 매뉴얼」을 받아 절차를 대조.
      **가입 유형·링크아이디 지정이 있으면 그것을 따른다**(4-1 참고)

### 4-1. 회원 유형 — 일반회원

| 유형 | 정의 | 요금 |
|---|---|---|
| **일반회원** ← 우리 | 팝빌 홈페이지에 접속해 직접 사용 | 표준 요금제, 결제액 일부 보너스 포인트 적립 |
| 서비스 연동회원 | 쓰는 프로그램을 팝빌 API와 연동. **파트너(연동사) 하위 계정**으로 등록되고 가입도 파트너를 통해 한다 | 연동사와 별도 협의 |

우리가 할 일은 토스가 보낸 역발행 건을 팝빌 웹에서 승인하는 것뿐이고 연동할 프로그램이 없다. → **일반회원**.

주의: 팝빌은 **사업자등록번호 기준으로 중복 등록이 불가**하고 유형 변경 가능 여부는 확인되지 않았다.
그래서 토스 매뉴얼에 가입 유형 지정이 있으면 그쪽을 먼저 따른다.

## 5. 매월 반복되는 일 — 놓치면 앱이 멈춘다

| 시점 | 할 일 |
|---|---|
| 매월 1일 | 지난달 수익이 콘솔에 업데이트된다 |
| 매월 2영업일 오후 3시 이내 | 토스가 **승인 요청 메일**을 보낸다 |
| **매월 4영업일까지** | 팝빌에서 내용 확인 → [발행] → 인증서로 전자서명 |
| 익월 말일 | 정산금 입금 |

**놓쳤을 때**

| 횟수 | 결과 (가이드 원문) |
|---|---|
| 1회 | "기한 내 승인하지 않으면 정산금 지급이 이월돼요" |
| **2회 이상** | **"미니앱 운영이 중단될 수 있어요"** |

승인 마감이 월초 4영업일이라 연휴가 끼면 실제 여유가 이틀 남짓이다.
승인 요청 메일이 스팸으로 가지 않는지 미리 확인하고, 달력에 매월 초 알림을 걸어 두는 편이 안전하다.

### 5-1. 발행 비용 — 기본값이 우리 부담이다

역발행에서 최종 승인은 공급자가 하지만, **발행 과금의 기본 설정은 "공급자 과금"** 이다.
승인하면 우리 팝빌 포인트에서 차감된다. 건당 소액이지만 **잔액이 0이면 승인이 막힌다.**
승인 마감이 월초 4영업일이고 2회 놓치면 운영이 중단될 수 있으므로 실제 위험이다.

- 설정 위치: `전자세금계산서 > 환경설정 > 세금계산서 관리 | 역발행 및 위수탁 설정`
  에서 공급자 과금 / 공급받는자 과금을 고른다.
- 토스가 부담하는 구조로 안내돼 있는지는 확인되지 않았다 → 매뉴얼 확인 또는 채널톡 문의.
  그때까지는 **소액이라도 포인트를 채워 두는 편이 안전하다.**

기타
- 정산 받을 수입이 **5,000원 이하면 다음 달로 이월**해 누적한다.
- 세금계산서 승인 외의 세무 업무는 앱인토스가 지원하지 않는다.

## 6. 변경 이력
- 2026-09-07 초안. fx-replay SUBMISSION 3-3에 흩어져 있던 내용을 사업자 공통 문서로 분리하고,
  공식 가이드로 대조해 인증서 종류 제한과 "2회 이상 미승인 시 운영 중단"을 추가했다.
- 2026-09-07 회원 유형(일반회원)과 업태·종목, 역발행 기본 과금이 공급자 부담이라는 점을 추가.
  미확인으로 뒀던 과금 주체 질문에 기본값이 있다는 답을 찾았다.
- 2026-09-07 카카오뱅크 사업자 인증서(무료, 민간 인증서)를 3-2로 추가. 팝빌 호환이 미확인이라
  문의 후 판단하도록 했다. "정산 계좌 은행에서 발급"이라고 적어 둔 것도 정정 — 둘은 무관하다.
- 2026-09-07 인증서 발급처와 등록처가 다르다는 점을 3-1로 분리. 팝빌 "인증서 관리"에
  4,400원짜리가 없는 것이 정상이다(팝빌은 자기 상품만 판다).
- 2026-09-07 인증서 3장 정정. "은행 인증서는 안 된다"고 뭉개 적어 두었는데 틀렸다.
  은행에서 발급하는 **전자세금계산서용**(연 4,400원 선)이 팝빌 권장이고, 안 되는 것은
  **금융거래용**이다. 팝빌 표준 공동인증서(4만 원대)를 살 필요가 없다는 점을 명시했다.
