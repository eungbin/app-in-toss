# job-benefit (실업급여 계산기) 상태

파생할 수 있는 것(광고 ID 단계, deploy 스크립트, 가드, 마지막 커밋)은 여기 적지 않는다.
루트에서 `npm run status` 로 본다. 이 파일에는 **파일에서 읽어낼 수 없는 것만** 적는다 —
콘솔 등록·심사·정산처럼 앱인토스 쪽에만 있는 사실이다.

- **단계**: **문서 1~2단계** (2026-09-10 후보 비교·PROJECT_CONTEXT 작성. 7장 확인 필요 7건이 열려 있다)
- 갱신: 2026-09-10

## 콘솔

- **앱 슬롯 없음.** 아직 콘솔에 등록하지 않았다. `appName` `job-benefit` 은 문서상 잠정값이고 등록 전까지 바꿀 수 있다.
- 광고 그룹 0개. 출시 전에 리워드·배너 2개를 만든다.
- 사업자·정산 정보는 공통 항목으로 이미 등록돼 있다([PLAYBOOK 3장](../docs/PLAYBOOK.md)).
