## 1. 산식과 원문 (자동 대조된다)

아래 상수는 `src/data/legal.json` 에 있고, **`npm run data:build` 가 조문 원문과 문자열로 대조한다.**
값이 바뀌거나 조문이 개정되면 빌드가 실패한다([DATA_VERIFICATION 1-2](DATA_VERIFICATION.md)).

| 산식 | 원문 | 대조 문구 |
|---|---|---|
| 피보험 단위기간 180일 | 고용보험법 제40조①1 | `피보험단위기간…이합산하여180일이상일것` |
| 기준기간 18개월 | 법 제40조② | `기준기간은이직일이전18개월로하되` |
| 일액 = 기초일액 × 60% | 법 제46조①1 | `기초일액에100분의60을곱한금액` |
| 최저구직급여일액 = × 80% | 법 제46조①2 | `기초일액에100분의80을곱한금액` |
| 대기기간 7일 | 법 제49조① | `7일간은대기기간으로보아구직급여를지급하지아니한다` |
| 기초일액 상한 113,500원 | 시행령 제68조① | `11만3500원` |
| 조기재취업 14일 경과 | 시행령 제84조① | `실업의신고일부터14일이지난후재취업한수급자격자` |
| 조기재취업 잔여 1/2 | 시행령 제84조① | `소정급여일수를2분의1이상남기고재취업한경우` |
| 계속 고용 12개월 | 시행령 제84조①1 | `12개월이상계속하여고용된경우` |
| 수당 = 일액 × 미지급일수 × 1/2 | 시행령 제85조① | `구직급여일액에미지급일수의2분의1을곱한금액` |
| 1일 소정근로시간 (주) ÷48×8 | 시행규칙 제91조의2 | `48시간×8시간` |
| (월) ÷209×8 | 같은 조 | `209시간×8시간` |
| (주마다 다름) ÷28 | 같은 조 | `÷28` |
| 평균임금 정의 | 근로기준법 제2조①6 | `3개월동안에그근로자에게지급된임금의총액을그기간의총일수로나눈금액` |
| 최저기초일액 정의 | 고용보험법 제45조④ | `이직전1일소정근로시간에…최저임금액을곱한금액` |

별표 2건도 `data:build` 가 검증한다 — 별표 1은 표를 파싱해 단조성·경계값(120·270)을 확인하고, 별표 2는 옮겨 적은 14개 항목이 **원문에 문자열로 존재하는지** 공백을 지운 뒤 대조한다.

## 2. 골든 케이스 (원문 숫자 리터럴 산술)

전건 `scripts/golden.test.ts` 에 있고 `npm run test:run` 이 돌린다. 2026년 최저임금 10,320원 기준.

경계 케이스는 단위 테스트에 있다 — 기초일액 110,080(60%가 하한과 같아지는 지점)·110,100·113,500, 50세 경계, 피보험기간 5구간 경계, 조기재취업 잔여 89·90·91일, 신고 후 14·15일, 3개월 총일수 90·91·92일.

**총액이 감소하는 지점이 정확히 한 곳(91일째)임을 테스트로 고정했다.** 이 계단이 S03 화면의 전부다.

## 3. 남은 검증 — 공공 계산기 대조 (미완)

| 대상 | 상태 |
|---|---|
| 고용보험 실업급여 모의계산 | **미조회.** 페이지 경로부터 확인해야 한다(추측 URL을 문서에 남기지 않는다) |
| 원 단위 절사 규칙 | **미확정.** 원문에 없다. 지금은 최종 일액에서만 1원 미만 버림. 하한값(66,048 등)은 절사와 무관해 G1·G3·G6·G7·G10·G12·G13 은 영향이 없고, **G8·G11 처럼 60%가 실제로 작동하는 케이스만 영향을 받는다** |
| 3개월 산정 기간의 경계 | **미확정.** 지금은 이직일 직전 3개월(이직일 제외). 총일수가 90~92로 흔들리면 평균임금이 최대 2% 움직인다 |

세 건 모두 `check:data` 가 경고로 띄운다(`legal.json` `needsVerification`). **화면 구현 전에 닫는다.**
