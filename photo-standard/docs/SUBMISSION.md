### 1-2. 상세 설명 (콘솔 "상세 설명" 필드)

콘솔 가이드가 요구하는 **"서비스 접속 → 행동 → 결과"** 흐름으로 썼다.
**500자 이내**여야 한다(줄바꿈·공백도 센다). 아래는 **492자**다. 고치면 길이를 다시 센다.

> 여권·비자·운전면허 등 온라인 민원에 제출하는 사진을 각 기관이 공개한 규격에 맞추는 도구입니다.
>
> 앱에 들어오면 사진을 고르는 화면이 나옵니다. 앨범이나 카메라에서 사진을 고르고 용도를 선택하면, 지금 사진의 가로·세로 픽셀과 파일 용량, 비율이 그 규격에 맞는지 항목별로 확인할 수 있습니다. 여권(온라인·인화), 운전면허, 미국 비자, 증명사진 규격을 제공하고 직접 입력할 수도 있습니다.
>
> 기준을 넘은 항목이 있으면 규격에 맞추기를 눌러 비율에 맞게 자르고, 크기와 용량을 줄인 사진을 기기에 저장합니다. 비율이 이미 맞으면 자르기를 건너뜁니다. 원본이 규격보다 작으면 늘리지 않고 알려 드립니다.
>
> 모든 처리는 기기 안에서 이루어지며 사진은 서버로 전송되거나 저장되지 않습니다. 배경 제거나 얼굴 보정 기능은 제공하지 않습니다. 기관의 최종 심사 결과를 보장하지 않으며, 규격의 출처와 확인일을 화면에 표시합니다. 사용자 간 경쟁, 현금성 보상, 확률형 요소가 없습니다.

심사에서 필요한 진술을 모두 넣었다 — **기기 내 처리·서버 미전송**(이 앱의 가장 큰 심사
리스크), **배경 제거·보정 미제공**(외교부 반려 사유와 직결), **심사 결과 미보장**,
**출처·확인일 표시**, 경쟁·현금성 보상·확률형 요소 없음.

"통과·합격·승인"을 쓰지 않았다. `lint-copy` 가 앱 문구에서 막는 어휘이고, 제출 자료에서도
같은 기준을 지킨다.

## 2. 심사에서 물을 만한 것

이 앱은 **얼굴 사진을 다룬다.** 다른 세 앱에 없던 렌즈다.

| 질문 | 답 |
|---|---|
| 사진을 어디에 저장하나 | 어디에도 저장하지 않는다. 서버가 없고, 앱 저장소에도 이미지를 넣지 않는다. Storage 에 두는 것은 마지막 프리셋 선택과 일일 저장 횟수뿐이다 |
| 처리는 어디서 하나 | 기기 안 Canvas 2D. 네트워크 호출은 광고 SDK 뿐이다 |
| 권한을 언제 요청하나 | 사용자가 [앨범에서 고르기] 또는 [카메라로 찍기]를 누른 시점에만. 진입 즉시 요청하지 않는다 |
| 규격 수치의 근거는 | 외교부 여권안내, 도로교통공단, 미국 국무부. 화면(S05)에 기관명·원문 링크·확인일을 표시한다 |
| 발급을 보장하나 | 하지 않는다. 결과 화면에 "기관의 최종 심사 결과는 이 앱이 보장하지 않아요"를 고정 노출하고, "통과·합격·승인"을 빌드에서 금지어로 막는다 |
| 배경을 지워 주나 | 제공하지 않는다. 외교부가 배경을 편집으로 제거한 사진을 반려 사유로 명시했다 |

### 3-3. 로고

크롭 브래킷 넷. 규격을 맞추는 앱이라 "프레임을 씌운다"가 가장 직접적인 상징이고, 자르기
