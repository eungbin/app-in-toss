# 화면 흐름 — photo-standard ("사진규격")

| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.1 (2026-09-08) |
| 상위 문서 | [PRD.md](PRD.md) v0.1, [FUNCTIONAL_SPEC.md](FUNCTIONAL_SPEC.md) v0.1 |
| 화면 ID | 기능 명세 2장과 동일 (S01 ~ S05, M01 ~ M03) |

이 문서는 화면 배치·이동·문구를 확정한다. 구현 전 `/design` 캔버스로 시안을 만들어 승인받는다 ([PLAYBOOK 0장 7](../../docs/PLAYBOOK.md)).

## 1. 네비게이션 맵

```
                    intoss://photo-standard/
                              │
                              ▼
                    ┌───────────────────┐
                    │  S01  홈           │◀────────────────┐
                    │  사진 고르기 +      │                 │
                    │  프리셋 선택        │                 │
                    └─────────┬─────────┘                 │
                              │ 앨범/카메라                  │
                              │ (권한 거부 → M03)            │
                              ▼                            │
                    ┌───────────────────┐                  │
                    │  S02  판정         │                  │
                    │  항목별 OK/초과     │                  │
                    └─────────┬─────────┘                  │
                       ┌──────┴──────┐                     │
              비율 불일치 │             │ 비율 OK             │
                       ▼             │                     │
             ┌───────────────┐       │                     │
             │  S03  자르기   │───────┤                     │
             │  비율 고정     │       │                     │
             └───────────────┘       │                     │
                                     ▼                     │
                           ┌───────────────────┐           │
                           │  S04  결과         │           │
                           │  미리보기 + 저장    │           │
                           └─────────┬─────────┘           │
                                     │ 저장                 │
                          상한 초과? ─┴─▶ M01 리워드 시트    │
                                     │                     │
                                     ▼                     │
                                  저장 완료 ────────────────┘

        S01·S02 하단 [규격 출처] ──▶ S05 출처
```

**뒤로가기 규칙**
- 스택이 남아 있으면 한 겹 벗는다 (S04 → S03 또는 S02, S02 → S01).
- S01에서 뒤로가기 = 미니앱 종료.
- 바텀시트·다이얼로그에서 백버튼 = 닫기. 광고 표시 중 백버튼은 SDK가 처리한다.
- **S04에서 뒤로 갔다 다시 오면 변환을 다시 하지 않는다.** 결과를 메모리에 들고 있다.

**탭바가 없다.** 화면 다섯 개의 단일 흐름이라 탭이 필요 없다. net-pay와 다른 점이다.

## 2. 공통 레이아웃 규칙

### 2-1. 앱인토스 네비게이션 바
- 토스가 그리는 네비게이션 바 사용 (`withBackButton`, `withHomeButton`, `withTitle`, 라이트). 자체 헤더·뒤로가기 버튼 없음.
- 타이틀: S01 "사진규격", S02 "규격 확인", S03 "사진 자르기", S04 "완성", S05 "규격 출처".

### 2-2. 세이프 에어리어·그리드
- **CSS `env(safe-area-inset-*)` 를 쓰지 않는다.** kit `useSafeArea()` 가 내보내는 `--safe-top` / `--safe-bottom` 만 쓴다 (fx-replay 이중 적용 사례).
- 좌우 여백 20, 카드 간격 12, 카드 내부 여백 16.
- **이미지 미리보기 영역은 화면 세로의 45%를 넘지 않는다.** 넘으면 판정 결과와 버튼이 접히는 곳 아래로 밀린다.
- 배너는 항상 스크롤 콘텐츠의 마지막 요소.

### 2-3. 이미지 표시 규칙
- 미리보기는 항상 **비율 유지 `contain`**. 잘라 보여 주지 않는다. 사용자가 원본을 오해하면 안 된다.
- 이미지 뒤 배경은 `--surface`(회색). 흰 사진과 흰 배경이 붙으면 경계가 사라진다.
- **체커보드 패턴을 쓰지 않는다.** 투명 배경을 다루지 않는 앱이라 오해만 만든다.

### 2-4. 상태 변주
| 상태 | 표현 |
|---|---|
| 사진 없음 | S01의 미리보기 자리에 안내: "사진을 고르면 규격에 맞는지 확인해 드려요" |
| 처리 중 | 버튼 내 스피너. 전체 화면 로딩 오버레이 금지 (보통 1초 안에 끝난다) |
| 권한 거부 | M03 안내 다이얼로그 |
| 판정 blocked | S02에서 저장 경로를 막고 다시 고르기만 남긴다 |
| 압축 실패 | S04에서 경고 배지 + 문구. 저장 버튼은 살려 둔다 |

## 3. 화면별 와이어프레임

### S01 홈

```
┌─────────────────────────────┐
│ 사진규격          (토스 네비)  │
├─────────────────────────────┤
│                             │
│   ┌───────────────────┐     │
│   │                   │     │
│   │   사진을 고르면      │     │  ← 미리보기 자리 (빈 상태)
│   │   규격에 맞는지      │     │     사진 선택 후 이 자리에 미리보기
│   │   확인해 드려요      │     │
│   │                   │     │
│   └───────────────────┘     │
│                             │
│  [ 앨범에서 고르기 ]  ← primary │
│  [ 카메라로 찍기  ]  ← 보조    │
│                             │
│  어디에 쓸 사진인가요?          │
│  ┌──────┐┌──────┐┌──────┐   │
│  │여권   ││여권   ││운전면허│   │  ← 프리셋 칩 (가로 스크롤)
│  │온라인 ││인화용 ││온라인 │   │
│  └──────┘└──────┘└──────┘   │
│  ┌──────┐┌──────┐┌──────┐   │
│  │미국   ││증명사진││직접   │   │
│  │비자   ││ 3×4  ││입력   │   │
│  │      ││[관행] ││      │   │  ← 관행 배지
│  └──────┘└──────┘└──────┘   │
│                             │
│  선택한 규격                  │
│  ┌─────────────────────┐    │
│  │ 413 × 531 px        │    │  ← 가장 큰 글자 = 그 화면의 답
│  │ 500KB 이하 · JPG     │    │
│  │ 외교부 · 2026-09-08   │    │
│  └─────────────────────┘    │
│                             │
│  사진은 이 기기 안에서만        │  ← 고정 문구 (원칙 A4)
│  처리돼요. 어디에도            │
│  올라가지 않아요.              │
│                             │
│  [규격 출처 →]                │
│  ─────── 배너 광고 ────────   │
└─────────────────────────────┘
```

- 프리셋을 먼저 골라도 되고 사진을 먼저 골라도 된다. 둘 다 있으면 자동으로 S02로 간다.
- 마지막에 쓴 프리셋이 기본 선택 (PR-6).
- **"선택한 규격" 카드가 이 화면에서 가장 큰 글자다.** 사용자가 알고 싶은 건 목표 숫자다.
- 관행 프리셋(`id-3x4`)에는 `[관행]` 배지. 기관 프리셋에는 기관명·확인일.

### S02 판정

```
┌─────────────────────────────┐
│ ← 규격 확인                   │
├─────────────────────────────┤
│   ┌───────────────────┐     │
│   │                   │     │
│   │    [ 미리보기 ]     │     │  ← contain, 회색 배경
│   │                   │     │
│   └───────────────────┘     │
│                             │
│  여권 (온라인 신청) 기준         │
│  ┌─────────────────────┐    │
│  │ ✓ 가로   1200 → 413  │    │
│  │ ✓ 세로   1600 → 531  │    │
│  │ ! 용량   1.8MB       │    │  ← 초과 항목
│  │        500KB 이하 필요 │    │
│  │ ! 비율   3:4          │    │
│  │        자르기가 필요해요 │    │
│  │ ✓ 형식   JPG         │    │
│  └─────────────────────┘    │
│                             │
│  [ 규격에 맞추기 ]  ← primary  │
│                             │
│  [다른 사진 고르기]             │
│  [규격 출처 →]                │
└─────────────────────────────┘
```

- 항목은 **아이콘 + 문구**로 표시한다. 색만으로 구분하지 않는다 (접근성).
- 초과 항목에는 "무엇이 필요한지"를 함께 쓴다. 문제만 알리고 끝내지 않는다.
- **`overall === 'pass'`** 면 항목이 전부 ✓ 이고 버튼은 [이대로 저장하기].
- **`overall === 'blocked'`** 면:
  ```
  ┌─────────────────────┐
  │ 이 사진은 기준보다 작아요 │
  │ 413 × 531 이 필요한데   │
  │ 320 × 400 이에요       │
  │ 크게 늘리면 흐려져서      │
  │ 그대로 두었어요          │
  └─────────────────────┘
  [ 다른 사진 고르기 ]
  ```
  저장 경로를 막는다.

### S03 자르기

```
┌─────────────────────────────┐
│ ← 사진 자르기                  │
├─────────────────────────────┤
│                             │
│  ┌───────────────────────┐  │
│  │░░░░░░░░░░░░░░░░░░░░░░░│  │  ← 어두운 마스크
│  │░░┌─────────────┐░░░░░░│  │
│  │░░│             │░░░░░░│  │
│  │░░│  크롭 박스    │░░░░░░│  │  ← 비율 고정, 이동·확대만
│  │░░│  3.5 : 4.5   │░░░░░░│  │
│  │░░│             │░░░░░░│  │
│  │░░└─────────────┘░░░░░░│  │
│  │░░░░░░░░░░░░░░░░░░░░░░░│  │
│  └───────────────────────┘  │
│                             │
│  비율은 규격에 맞춰 고정돼 있어요  │
│  움직이거나 크기만 바꿀 수 있어요  │
│                             │
│  [ 이대로 맞추기 ]  ← primary  │
└─────────────────────────────┘
```

- 크롭 박스의 **비율은 바꿀 수 없다.** 모서리 핸들을 두지 않는다 (핸들이 있으면 비율을 바꿀 수 있다고 읽힌다). 대신 핀치 줌과 드래그.
- 박스는 소스 경계 안에 클램프된다.
- **축소 하한**에 닿으면 더 줄지 않고 짧은 진동(`generateHapticFeedback`)으로 알린다.
- 이 화면에 **광고를 두지 않는다** (PRD 원칙 D3).

- `notes` 는 프리셋이 가진 안내 문구를 그대로 쓴다. 앱이 검사하지 않는 조건임을 알 수 있게 면책 문구와 한 덩어리로 둔다.
- 저장 성공 → 토스트 "앨범에 저장했어요".

## 4. 핵심 플로우 시퀀스

**4-1. 해피 패스**
S01 [앨범에서 고르기] → 사진 선택 → S02 판정(비율 불일치) → [규격에 맞추기] → S03 자르기 → [이대로 맞추기] → 변환 → S04 → [사진 저장하기] → 토스트

**4-2. 비율이 이미 맞는 경우**
S01 → S02 판정(비율 ok, 용량만 초과) → [규격에 맞추기] → **S03을 건너뛰고** 바로 변환 → S04

**4-3. 저장 4장째**
S04 [사진 저장하기] → `checkGate` = `gate` → M01 → [광고 보고 계속하기] → `userEarnedReward` → `gateOpenUntil` 설정 → 저장 진행

**4-4. 원본이 너무 작을 때**
S01 → S02 판정 `blocked` → 안내 카드 + [다른 사진 고르기]만 노출 → S01

**4-5. 권한 거부**
S01 [앨범에서 고르기] → 권한 오류 → M03 → [설정 열기] 또는 [닫기] → S01

**4-6. 딥링크 진입**
`intoss://photo-standard/` → S01. 진입 즉시 시트·광고를 열지 않는다.

## 6. 디자인 토큰

net-pay가 실기기 지적 후 정리한 토큰 체계를 그대로 쓴다 ([net-pay SCREEN_FLOW 6장](../../net-pay/docs/SCREEN_FLOW.md)). 이 앱에서 더하는 것만 적는다.

### 6-1. 원칙 (net-pay와 공유)
1. **층은 셋뿐** — 배경(흰색) · 떠 있는 카드 · 가라앉은 블록(회색).
2. **그 화면의 답이 가장 큰 글자다.** S01은 목표 규격, S02는 판정, S04는 결과 크기.
3. **임의값 금지.** 크기·간격·굵기·모서리는 토큰에서만.

### 6-2. 이 앱이 더하는 토큰
| 갈래 | 토큰 | 값 | 용도 |
|---|---|---|---|
| 이미지 배경 | `--img-bg` | `--gray-100` | 미리보기 뒤. 흰 사진과 흰 배경이 붙는 걸 막는다 |
| 크롭 마스크 | `--crop-mask` | `rgba(0,0,0,.55)` | 크롭 박스 바깥 |
| 크롭 테두리 | `--crop-border` | `#fff`, 2px | 어두운 마스크 위에서 보여야 한다 |
| 판정 OK | `--verdict-ok` | `--primary` | 아이콘·문구 함께 |
| 판정 초과 | `--verdict-over` | `--warn` | 위험(빨강) 아님. 고칠 수 있는 상태다 |
| 판정 blocked | `--verdict-blocked` | `--danger` | 고칠 수 없는 상태 |
| 미리보기 높이 | `--preview-max-h` | `45vh` | 넘으면 결과·버튼이 접힌다 |

### 6-3. 규칙으로 굳힌 것 (net-pay에서 가져옴 + 이 앱 고유)
- **한국어는 어절로 끊는다** — `word-break: keep-all`.
- **`font` 단축 문법에 `inherit` 금지** — 선언 전체가 버려진다.
- **입력 필드 16px 이상** — 미만이면 iOS가 확대한다.
- **아이콘은 인라인 SVG만.** 이모지·글리프 금지.
- **(이 앱) 판정 상태를 색만으로 구분하지 않는다.** 아이콘(✓ / !)과 문구를 함께 쓴다.
- **(이 앱) 크롭 박스에 모서리 핸들을 두지 않는다.** 비율을 바꿀 수 있다는 오해를 준다.
- **(이 앱) 이미지는 항상 `contain`.** 미리보기에서 잘라 보여 주면 원본을 오해한다.
