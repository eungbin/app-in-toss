# "사진규격" — 사진 규격 맞춤 앱 프로젝트 컨텍스트

> 이 문서는 **이미 출시된 앱의 소스 유실 복구**를 위한 인계 문서다(2026-09-08).
> 2장의 결정은 확정이므로 재논의하지 않는다. "확인 필요" 표시된 항목만 열려 있다.
> 네 번째 앱이지만 **신규가 아니라 복구**다. 선행 앱: [fx-replay](../../fx-replay/docs/PROJECT_CONTEXT.md), [net-pay](../../net-pay/docs/PRD.md), [rent-calc](../../rent-calc/docs/PROJECT_CONTEXT.md).

## 1. 한 줄 정의

**토스 앱인토스 미니앱**으로 **이미 출시되어 운영 중인** 사진 규격 맞춤 도구 "사진규격"(폴더·appName `photo-standard`, 영문명 `Resize Photo`). 사진을 고르면 **용도별 규격에 맞는지 판정하고 그 자리에서 맞춰 주는 것**이 메인 훅이고, 픽셀 리사이즈·용량 압축·자르기를 표준 기능으로 제공한다.

## 3. 복구 맥락 — 구판에서 알아낸 것과 잃은 것

### 3-1. 잃은 것
- **소스 전부.** 로컬(`~/dev` 전체), GitHub 저장소 61개, 이 저장소 git 히스토리 어디에도 없다.
- **콘솔에서 되받을 수도 없다.** 앱인토스는 빌드 산출물(`.ait`)만 보관하고, 콘솔 UI에 번들 내려받기가 없다. `ait` CLI의 배포 API도 `upload-start` / `upload-complete` / `deployments/<id>` 조회 셋뿐이다.
- 결론: **재구현이 유일한 길이다.**

### 3-3. 구판 성적 — 되풀이하지 말 것
- 2026-08-08 ~ 09-08 전체 유저 **4명**, 리텐션 DAY 1 이후 전부 **0%**.
- 인앱 광고 **미등록** → 수익 0.
- 출시 후 한 번도 갱신하지 않음.
- 유저 4명은 앱이 나빠서라기보다 **광고·유입 장치를 아무것도 붙이지 않은 결과**로 본다. 다만 리텐션 0%는 도구 앱의 정상 범위일 수 있다(1회 쓰고 끝나는 성격). **재방문을 KPI로 잡지 않는다.**

### 3-4. 복구의 비가역성 — 착수 전에 알고 시작한다
- **SDK 3.x 번들을 출시하면 2.x로 롤백할 수 없다**(개발자 문서 명시). 다만 2.x 소스가 없어 돌아갈 대상 자체가 없으므로 실질 손해는 없다.
- 새 번들은 **"검토 요청 → 승인 → 출시"** 심사를 다시 거친다. 비게임 최대 3영업일.
- 즉 **복구 = 재심사**다. [비게임 출시 가이드](https://developers-apps-in-toss.toss.im/checklist/app-nongame.md) 체크리스트를 처음부터 다시 통과해야 한다.

## 4. 규격 데이터 (원문 확인 완료, 2026-09-08)

외부 API 없이 **번들 상수**로 넣는다. 골든 테스트의 기대값은 [PLAYBOOK 0장 9](../../docs/PLAYBOOK.md)에 따라 **구현 코드를 거치지 않는 경로**(원문 수치 리터럴)로 만든다.

### 4-1. 여권 — 온라인 신청용 (핵심 프리셋)
출처: [외교부 여권안내 — 온라인용 사진파일 안내](https://www.passport.go.kr/home/kor/contents.do?menuPos=12)

| 항목 | 기준 |
|---|---|
| 권장 크기 | **413 × 531 px** |
| 허용 범위 | 395–431 px (가로) × 507–550 px (세로) |
| 형식 | **JPG/JPEG만** |
| 용량 | **500KB 이하** |
| 해상도 | 300dpi 권장 |
| 배경 | 흰색 |

**이 프리셋 하나가 앱의 존재 이유다.** 구판 출시노트 "픽셀 크기와 파일 용량을 변환해요"가 정확히 이 두 축(413×531 / 500KB)을 가리킨다.

### 4-2. 여권 — 인화용
출처: [외교부 여권안내 — 여권 사진](https://www.passport.go.kr/home/kor/contents.do?menuPos=32)
- 3.5 × 4.5 cm, 6개월 이내 촬영, 머리 길이(정수리~턱) **3.2 ~ 3.6 cm**
- 300dpi 환산 시 413 × 531 px — 4-1과 같은 픽셀값이다.
- ICAO 기준을 따른다.

### 4-3. 그 밖의 프리셋 (2026-09-08 확인)

| 프리셋 | 픽셀 | 용량 | 형식 | 출처 |
|---|---|---|---|---|
| 운전면허 (온라인) | **350 × 450** | — | — | [도로교통공단](https://www.safedriving.or.kr/guide/larGuide10.do?menuCode=MN-PO-12111) |
| 미국 비자·여권 | **600 × 600** (최대 1200 × 1200, **정사각 필수**) | **240KB 이하** | JPEG | [US Dept. of State](https://travel.state.gov/content/travel/en/us-visas/visa-information-resources/photos.html) |
| 증명사진 (3 × 4 cm) | 354 × 472 @300dpi | — | — | **관행 — 법정 근거 없음** |

- 운전면허는 **2016-02-01부터 인터넷 민원용 사진에 여권 규격을 적용**한다. 물리 규격은 여권과 같은 3.5 × 4.5 cm, 얼굴 길이 3.2 ~ 3.6 cm.
- 미국 비자는 **정사각 비율이 강제**다. 다른 프리셋과 유일하게 비율이 다르므로 자르기 UI에서 특별 취급한다. 머리 높이는 이미지 전체 높이의 50 ~ 69%.
- **증명사진 3 × 4 cm 는 법정 규격이 아니라 관행이다.** 이력서·학생증 등에서 굳어진 값일 뿐 근거 고시가 없다. 화면에서 여권·비자 프리셋과 **같은 무게로 보이면 안 된다** — "기관 기준"과 "일반 관행"을 구분해 표기한다.

### 4-4. 넣지 않기로 한 것 — 배경 제거
외교부가 **"배경색을 사진 편집 프로그램으로 제거하여 사진이 변형된"** 사진을 반려 사유로 명시했다. 과도한 보정도 마찬가지다. 따라서:
- 배경 제거·배경색 교체·얼굴 보정 기능은 **v1.0에 넣지 않는다.**
- 넣으면 사용자를 반려로 밀어 넣는 앱이 된다. 기술 난이도가 아니라 **제품 판단**이다.

## 5. 지켜야 할 제약

- **심사**: 비게임 출시 가이드 체크리스트. 번들 100MB 이하(압축 해제 기준).
- **출시 번들에 테스트 광고 ID 문자열이 남으면 반려된다** — kit의 번들 스캔 가드를 채택한다([PLAYBOOK 6장](../../docs/PLAYBOOK.md), fx-replay 반려 사례).
- **권한**: 앨범·카메라 접근이 필요하다. `apps-in-toss.config.ts` 의 `permissions` 에 선언하고, 거부됐을 때의 화면을 반드시 만든다.
- **개인정보**: 사진은 기기를 벗어나지 않는다. 업로드·전송·저장 서버가 없다는 사실을 화면과 심사 자료에 명시한다.
- **세이프 에어리어는 SDK 값으로.** CSS `env(safe-area-inset)` 를 쓰면 호스트 값과 이중 적용된다(fx-replay 사례). kit의 safe-area를 쓴다.
