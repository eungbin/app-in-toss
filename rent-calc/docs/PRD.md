## 1. 서비스 정의

### 1-1. 한 줄 정의
갱신이나 계약 기간 중에 집주인이 제안한 보증금·월세를 입력하면 **주택임대차보호법의 상한(증액 5%, 보증금→월세 전환율) 안인지 판정**하고, 상한 안에서 가능한 최대치를 알려 주는 계산기. 전세↔월세 환산, 중개보수 상한, 임대차 신고 대상 판정을 표준 기능으로 제공한다.

### 1-2. 무엇이 아닌가 (심사 대응의 출발점)
- 금융 상품을 팔거나 연결하는 앱이 아니다. 전세자금대출·보증보험·월세 카드납 어떤 상품도 노출·추천·링크하지 않는다.
- 법률 자문이 아니다. 모든 결과는 **법령 수치에 따른 참고 판정**이며 개별 계약·조례·특약에 따라 다를 수 있음을 결과 화면마다 명시한다. "위반"이라고 단정하지 않고 "법정 상한 초과"로 표현한다.
- 부동산 중개·매물·시세 서비스가 아니다. 중개보수는 "상한 계산"만 한다.
- 개인정보를 수집하지 않는다. 입력값은 기기 안에서만 계산되고 서버로 전송되지 않는다(서버 자체가 없다). 저장은 앱인토스 Storage에만 한다.
- 게임이 아니다. 랭킹·보상·확률 요소가 없다.

### 1-3. 왜 이 조합인가
1. **수요**: 전월세 계약·갱신은 20~30대 세입자가 2년마다 반드시 겪는 사건이고, 그때마다 "이 인상 받아도 되나"를 검색한다. 시즌성 없이 상시 발생한다.
2. **문맥**: 토스 사용자는 월세 자동이체·보증금 이체를 하다가 들어온다. 판정 결과는 바로 집주인과의 대화에 쓰인다.
3. **비어 있는 자리**: 공공 계산기(한국부동산원 전월세 전환, 렌트홈 임대료 인상률)는 "환산"과 "인상률 계산"을 각각 따로 제공한다. 제안 조건을 한 번 넣어 **판정 + 법정 최대치 + 중개보수 + 신고 여부**를 한 화면에 내는 도구는 없다. 앱인토스 안에도 없다.
4. **라이선스·정확성**: 계산 규칙이 전부 법령 조문과 별표다(저작권법 제7조, 보호 대상 아님). 기준금리는 한국은행 작성 ECOS 통계로 출처 표시만 하면 상업 이용 가능([[ecos-license-by-source-org]]). 중개보수 별표는 국가법령정보센터 평문으로 자동 수집된다(확인 완료).
5. **데이터 크기**: 기준금리 변동 시점 수십 행, 별표 20행, 상수 10개. 전부 번들.

### 1-4. 타깃 사용자
- 토스 사용자(만 19세 이상) 중 전월세 세입자. 특히 갱신 통보나 반전세 전환 제안을 받은 20~30대.
- 사용 시간 1~3분. 한 번에 끝나는 도구형 사용. 계약 시점에 몰리는 이벤트형 방문.
- 페르소나: "집주인이 월세 5만 원 올리자는데 이게 5%인지 모르는 사람" / "전세 1억 5천을 보증금 5천 + 월세로 돌리자는 제안을 받은 사람" / "중개사가 부른 수수료가 상한인지 확인하고 싶은 사람".

### 1-5. 성공 지표 (출시 후 90일)

| 지표 | 목표 | 측정 |
|---|---|---|
| 세션당 판정·계산 수 | 1.8회 이상 | 자체 이벤트 `judge_done` + `calc_done` |
| 판정 사용 비율 (전체 계산 중) | 50% 이상 | `judge_done` / 전체 |
| 리워드 광고 시청률 (게이트 진입자 중) | 35% | `ad_reward_earned` / `gate_view` |
| 공유 카드 생성률 (판정 결과 도달자 중) | 10% | `share_card_created` (판정 결과는 대화에 쓰이므로 net-pay보다 높게) |
| 30일 재방문율 | 10% | 앱인토스 분석 대시보드 (계약 시점형이라 net-pay보다 낮게) |
| 심사 | 1차 제출 반려 0건 | 콘솔 반려 사유 |

## 2. 심사 대응 원칙 (설계 제약)

### 2-1. 원칙 A — 금융 상품과의 거리
정책: "대출·보험·카드·증권 등 금융 상품 관련 서비스는 … 등록할 수 없어요."

| 규칙 | 구현 |
|---|---|
| A1. 상품 노출 0 | 전세자금대출·보증보험(HUG·HF·SGI)·월세 카드납·적금 어떤 상품명·유형도 화면에 없다. "이 보증금이면 대출 한도는" 류 파생 기능 금지. |
| A2. 카테고리 | 유틸리티로 등록. 재테크·금융은 금융 조항 렌즈로 검토되므로 피한다(fx-replay·net-pay와 같은 판단). 부동산 중분류가 있으면 심사 기준 차이를 사전 상담에서 확인. |
| A3. 외부 링크 | 법령·공공 계산기 출처 링크, 임대차분쟁조정위원회 안내 링크, 고객문의 이메일만. 토스 금융 서비스 딥링크 없음. |
| A4. 토스 자체 기능과 중복 회피 | 토스가 직접 제공하는 부동산·대출 영역으로 확장하지 않는다. 매물·시세 없음. |

### 2-2. 원칙 B — 법률 자문이 아닌 참고 판정
정책 직접 조항은 없으나 변호사법(법률 사무)과 심사 시 "정확성 책임" 질의에 대비. **판정 앱이라 net-pay보다 이 원칙이 더 중요하다.**

| 규칙 | 구현 |
|---|---|
| B1. 면책 문구 고정 | 모든 결과 화면 하단: "주택임대차보호법·공인중개사법 수치 기준 참고용 판정입니다. 개별 계약·특약·조례에 따라 다를 수 있어요." |
| B2. 기준일 표기 | 결과마다 적용 기준 표기: "기준금리 3.00% (2026-08-27 한국은행 공시) · 전환율 상한 연 5%". |
| B3. 단정·권고 금지 | "위반", "불법", "소송", "거절하세요", "받아들이세요" 없음. 판정은 "법정 상한 안이에요 / 법정 상한을 ○○원 넘어요" 두 가지 서술과 근거 산식만. `lint-copy` 금지어 사전을 이 서비스용으로 교체해 빌드 시 차단. |
| B4. 적용 범위 명시 | **신규 계약에는 상한이 없다.** 첫 화면에서 "갱신·기간 중 변경 / 신규 계약"을 먼저 고르게 하고, 신규에서는 판정을 끄고 환산 참고치만 보인다. 이걸 흐리면 잘못된 "초과" 판정을 내보내게 된다. |
| B5. 합의의 효력은 요구권 행사 여부로 갈림 | "상한 초과" 결과에 해설집(국토부·법무부 2020-08, FAQ Q3·Q3-1) 기준 사실 안내 두 줄: "계약갱신요구권을 행사한 갱신이면 5%를 넘는 부분은 효력이 없고 반환을 청구할 수 있어요" / "요구권을 행사하지 않고 합의한 새 계약이면 5%를 넘을 수 있어요(요구권은 나중에 1회 남아요)". 권고 없음. 상담 창구는 임대차분쟁조정위원회. |

### 2-3. 원칙 C — 개인정보 최소화
| 규칙 | 구현 |
|---|---|
| C1. 서버 없음 | 입력값은 기기 내 계산. 네트워크 호출은 앱인토스 SDK(광고)만. |
| C2. 저장 최소 | 사용자가 명시적으로 "저장"한 계산만. 앱인토스 Storage API. 삭제 버튼 제공. 주소·집주인 이름 입력란 없음. |
| C3. 식별 | `User.getAnonymousKey`만. 토스 로그인 없음(v1.0). |
| C4. 문구 | 첫 화면 하단 한 줄: "입력한 금액은 이 기기 안에서만 계산돼요." |

### 2-4. 원칙 D — 광고 보상은 기능 잠금 해제만
net-pay 2-4와 동일. 보상 = "시간축·저장 20개 오늘 하루 열기". `userEarnedReward`에서만 지급. 배너는 스크롤 콘텐츠 마지막 요소만.

### 2-5. 콘솔 상세 설명 문구 (초안)

> **서비스 설명**
> "월세 이거 맞아?"는 주택임대차보호법·공인중개사법과 한국은행 기준금리를 바탕으로 전월세 조건을 계산하는 도구입니다.
> 사용자는 (1) 갱신이나 계약 기간 중 제안받은 보증금·월세가 법정 상한(증액 5%, 보증금→월세 전환율) 안인지 확인하고, (2) 전세와 월세를 서로 환산하고, (3) 중개보수 상한과 임대차 신고 대상 여부를 확인할 수 있습니다. 같은 보증금의 전환 상한 월세가 연도별 기준금리에 따라 어떻게 달랐는지도 비교할 수 있습니다.
> 본 서비스는 금융 상품을 소개·연결하지 않으며, 매물·시세 정보를 제공하지 않고, 모든 결과는 참고용 계산값입니다. 입력값은 서버로 전송되지 않고 기기 안에서만 처리됩니다. 사용자 간 경쟁, 현금성 보상, 확률형 요소가 없습니다.
> 데이터 출처: 주택임대차보호법·시행령, 공인중개사법 시행규칙 별표 1·2(국가법령정보센터), 한국은행 ECOS 기준금리(722Y001).

> **수익 항목**: 인앱 광고 — 보상형(시간축 비교·저장 확장 1일 열기), 배너(홈·결과 화면 하단). 토스 애즈 SSP만 사용. 인앱결제 없음(v1.0).

## 3. 핵심 사용자 흐름

```
홈(=판정) ─┬─ [갱신·기간 중 변경] 현재 보증금·월세 + 제안 보증금·월세 ──▶ 판정 결과(상한 안/초과, 초과액, 법정 최대치)
           │                                                            ├─ 시간축 카드 "이 보증금, 2021년이었다면"   ◀ 게이트
           │                                                            ├─ 판정 카드 만들기(공유)                     (무료)
           │                                                            ├─ 이 계약의 중개보수 상한 / 신고 대상 보기    (무료)
           │                                                            └─ 이 계산 저장
           ├─ [신규 계약] 보증금·월세 ──▶ 환산 참고치 + "신규 계약엔 상한이 없어요" + 중개보수·신고 링크
           ├─ [전세↔월세 환산] ──▶ 보증금 ↔ 월세 (법정 전환율 기본, 직접 입력 가능)
           ├─ [중개보수] ──▶ 보증금·월세(·오피스텔 토글) ─ 거래금액 환산 ─ 상한요율·한도액 ─ 최대 중개보수(VAT 별도)
           ├─ [임대차 신고] ──▶ 보증금·월세·계약일 ─ 대상 여부·기한·과태료 안내
           ├─ [저장한 계산] ─ 목록(무료 3개, 해제 20개)
           └─ [설정] 기준금리·전환율 기본값, 데이터 출처·기준일, 저장 삭제, 고객문의, 다른 미니앱
```

### 3-1. 첫 화면 = 판정 (핵심)
1. 최상단 세그먼트: **갱신·기간 중 변경**(기본) / **신규 계약**. 원칙 B4.
2. 입력 두 묶음: "지금" 보증금·월세, "제안받은" 보증금·월세. 만 원 단위 숫자 키패드. 월세 0 = 전세.
3. 접힌 옵션: 마지막 계약·증액일(선택, 1년 규칙 안내용), 기준금리(기본 번들 최신값, 수정 가능).
4. 입력 즉시(디바운스 300ms) 결과 카드: 헤드라인 **"법정 상한 안이에요"** 또는 **"법정 상한을 월 ○○원 넘어요"**. 아래에 근거 3줄 — 환산보증금 기준 인상률 ○% (상한 5%), 적용 전환율 연 ○%, 법정 최대치("제안 보증금 그대로면 월세는 최대 ○○원까지").
5. 마지막 계약·증액일이 1년 미경과면 추가 한 줄: "직전 계약·증액 후 1년이 지나지 않아 증액 청구가 제한돼요."
6. 신규 계약 모드에서는 결과 카드 헤드라인이 "신규 계약에는 법정 상한이 없어요"로 바뀌고 환산 참고치(전환율 기준 보증금↔월세 환산)만 보인다. 판정 배지·초과액 없음.
7. 하단 기준일·면책(B1·B2) 고정.

### 3-2. 시간축 카드 (차별점, 게이트)
- 판정 결과 아래 "이 보증금, 2021년이었다면" 카드. 잠금 상태에서는 헤드라인만 보이고 수치는 자리표시자.
- 열면: 제안 보증금(또는 현재 보증금)을 전부 월세로 돌릴 때의 법정 상한 월세를 2021~2026 매년 1월 1일 기준금리 + 최신값으로 막대 7개. "기준금리가 ○%→○%로 바뀌어 같은 보증금의 전환 상한이 매달 ○○원 달라졌어요" 한 문장(서술형). 하단 표에 연도별 기준금리·전환율.
- 5% 증액 상한은 연도에 따라 변하지 않으므로 시간축은 전환율만 다룬다.

### 3-3. 판정 카드 (무료)
- 한 장 이미지: "제안 월세 ○○만 원 · 법정 상한 ○○만 원 · 기준금리 ○% 기준". 상한 안/초과 배지. 금액 숨김 토글 없음(판정 카드는 금액이 본질). 대신 "보증금 숨기기" 토글.
- `shareLink`로 공유. 딥링크 진입 시 같은 입력값이 채워진 상태로 열린다.
- **무료.** 서버 0 전략에서 신규 유입 수단은 공유 카드 하나. 카드 하단에 앱 이름·딥링크 고정.

### 3-4. 무료·광고 흐름
- **무료(항상)**: 판정·환산·중개보수·신고 판정 무제한, 판정 카드 생성·공유, 계산 저장 3개.
- **게이트(리워드 광고 → 오늘 하루 열기)**: 시간축 카드, 저장 3개 초과(최대 20). 광고 1회로 둘이 함께 열린다.
- 게이트 카드를 탭했을 때만 바텀시트. 열림 상태는 기기 로컬 자정까지.
- 리워드 광고는 홈 진입 시 프리로드. 배너: 홈·환산·중개보수·신고·저장 목록 최하단.

## 4. 기능 요구사항

우선순위: **P0 = 출시 필수**, P1 = 출시 후 4주 내, P2 = 검증 후.

### 4-1. 계산 엔진 (P0) — 순수 함수, 단위 테스트

| ID | 요구사항 |
|---|---|
| CE-1 | 법정 전환율 `legalConversionRate(baseRate) = min(0.10, baseRate + 0.02)`. 기준금리는 판정 시점(기본: 번들 최신값, 사용자 수정 가능). |
| CE-2 | 보증금→월세 환산 `depositToRent(amount, rate) = amount × rate ÷ 12` (원 미만 절사). 월세→보증금 `rentToDeposit(rent, rate) = rent × 12 ÷ rate`. 전환율은 법정값 기본, 사용자 입력 시 "시세 전환율(참고)"로 라벨 변경. |
| CE-3 | 환산보증금 `equivalentDeposit(deposit, rent, rate) = deposit + rent × 12 ÷ rate`. 현재·제안 조건을 같은 전환율로 환산한다. |
| CE-4 | 갱신 판정 `judgeRenewal(current, proposed, ctx)`: (a) 인상률 = (제안 환산보증금 − 현재 환산보증금) ÷ 현재 환산보증금. (b) 상한 5%(`INCREASE_CAP = 1/20`). (c) 초과 시 초과분을 **월세 환산액**(초과 환산보증금 × rate ÷ 12)과 **보증금 환산액** 둘 다 출력. (d) 법정 최대치: 제안 보증금을 고정했을 때 허용 최대 월세 = (현재 환산보증금 × 1.05 − 제안 보증금) × rate ÷ 12, 음수면 0과 "보증금만으로 상한 초과". (e) 마지막 계약·증액일 입력 시 1년 미경과 플래그. (f) 결과에 사용한 기준금리·전환율·기준일 포함. |
| CE-5 | 신규 계약 모드: 판정 없이 CE-2 환산만. 결과 타입에 `mode: 'new'`와 `verdict: null`. |
| CE-6 | 중개보수 상한 `brokerageCap(input)`: 거래금액 = 보증금 + 월세 × 100, 그 값이 5천만 원 미만이면 보증금 + 월세 × 70(`RENT_MULTIPLIER = 100 / 70`). 주택: 별표 1 임대차 구간(0.5/0.4/0.3/0.4/0.5/0.6%, 한도 20만/30만). 주거용 오피스텔 토글 on: 별표 2 임대차 0.4%(85㎡ 이하·전용 부엌·화장실·목욕시설 조건 문구 표시), 조건 미충족 선택 시 0.9% 협의. 결과 = min(거래금액 × 요율, 한도액). 부가세 별도 표기. 매매는 데이터만 포함, UI는 P1. |
| CE-7 | 임대차 신고 `reportRequired(deposit, rent, contractDate?)`: 보증금 > 6,000만 원 또는 월세 > 30만 원이면 대상(`REPORT_DEPOSIT = 60,000,000`, `REPORT_RENT = 300,000`, 초과 기준 — 정확히 6천만/30만은 대상 아님). 계약일 입력 시 기한 = 계약일 + 30일. 과태료 안내는 문구만(지연 2만~30만, 허위 100만). 지역 판정 없음 + 각주. |
| CE-8 | 시간축 `timeline(deposit, years[], baseRates)`: 각 연도 1월 1일 시점 유효 기준금리 → CE-1 → CE-2로 전액 전환 상한 월세. 최신값을 마지막 점으로 추가. 결과에 연도별 기준금리 포함. |
| CE-9 | 반올림·표시 규칙: 내부 정수 원. 전환·상한 월세·보증금은 **반올림**(부동산원·렌트홈 공공 계산기와 동일, [FACT_CHECK 5장](FACT_CHECK.md)). 중개보수 상한은 소수 발생 시 절사. 표시는 만 원 단위 "약" + 상세는 원 단위. 인상률은 소수 둘째 자리. |
| CE-10 | 골든 테스트: 한국부동산원·LH 전월세 전환 계산기(전환율·환산), 렌트홈 임대료 인상률 계산기(환산보증금 인상률), 서울시 중개보수 요율표 예시(거래금액 환산·한도액)와 최소 20개 케이스 대조. 기대값은 구현 코드를 거치지 않는 경로(법령 숫자 리터럴 산술)로 만들고 `docs/FACT_CHECK.md`에 기록. |
